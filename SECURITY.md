# Security

Report security issues in `metz-scan`, `rubocop-metz`, or this repository
privately via
[GitHub Security Advisories](https://github.com/fuentesjr/metz-scan/security/advisories/new)
(or a private vulnerability report if that option is available on the repo).
Do not open public issues for vulnerabilities.

Scope is the gems and repository tooling only. Design-pressure findings from
scans (`Metz/*` cops and `MetzProject/*` project analyzers) are quality and
architecture signals, not security findings.
