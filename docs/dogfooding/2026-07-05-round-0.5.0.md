## Headline-UX defects

Defect 1 is filed as #33. Defect 2's issue draft awaits filing (issue
creation for it was blocked mid-session pending user approval).

### 1. Default scan ignores the project's `.rubocop.yml` excludes

`runner.rb` passes `--force-default-config` in default (Metz-only) mode, which
discards the target project's entire `.rubocop.yml`, including
`AllCops: Exclude`. On redmine this produced 15 `Lint/Syntax` offenses against
`lib/generators/redmine_plugin_model/templates/migration.rb` — an ERB template
that redmine's own config explicitly excludes
(`'**/lib/generators/**/templates/*'`). Each offense also carries a repeated
`(Using Ruby 3.3 parser; configure using TargetRubyVersion ...)` hint that
points at the wrong cause. `--all-cops` mode does not pass the flag and honors
the exclude, so the two modes disagree about which files are scanned.

Minimal repro (verified against the released 0.5.0 gems): a project whose
`.rubocop.yml` excludes `lib/templates/**/*` containing an ERB-templated
`.rb` file gets `Lint/Syntax` offenses in default mode and none with
`--all-cops`.

### 2. `Metz/ControllersTooManyDirectCollaborators` counts non-collaborators and mislabels methods

With `Max: 1` the cop fires on most controller methods (74 offenses on
lobsters, 57 on maybe, 75 on rubygems.org), and verified spot checks show the
counting and labeling mislead:

- Rescue-clause exception classes count as collaborators: maybe's `set_chat`
  is `Current.user.chats.find(...)` + `rescue ActiveRecord::RecordNotFound`,
  reported as "reaches into 2 direct collaborators (Current,
  ActiveRecord::RecordNotFound)". lobsters' `banned_ips#index` similarly
  counts `Errno::ENOENT`/`Errno::EACCES`.
- Same-class constants count: lobsters' `remove_unknown_cookies` compares
  cookie keys against its own `TAG_FILTER_COOKIE`/`VALID_COOKIE_KEY`
  constants and is told to "funnel work through a single coordinator".
- Framework/stdlib constants count: `Rails`, `Time`, `File`, `Hash`,
  `SecureRandom` all appear as collaborators.
- Private helpers and `before_action` callbacks are labeled "Action"
  (`set_chat`, `find_user_from_rss_token`, `prepare_exception_notifier`).

The Metz signal (real orchestration soup like lobsters' `login` touching 11
constants) is present but drowned by these false collaborators.

## Findings-quality notes (queue candidates, not blocking)

- **No end-of-run summary for cop offenses.** Project analyzers get a
  detailed count header, but the 1,441 redmine `MethodsTooLong` lines end the
  report with no total, no files-inspected count, no per-cop rollup, and no
  top-offender view. On a legacy codebase the first impression is an
  unranked 1,800-line wall.
- **No adoption path for legacy codebases.** Every target produced hundreds
  of strict-by-design `[6/5]`/`[7/5]` MethodsTooLong offenses. Nothing in the
  output or README points at a way to adopt incrementally (todo-style
  baseline for cops, ranking, or "start with ClassesTooLong top offenders").
- **Cryptic RepeatedBranching subject on lobsters:** "`k` (state branch
  subject) branches in 2 files: Comment#as_json, Story#as_json". The
  duplication is real, but a bare block-variable name as the subject reads as
  noise; the generic-subject README guidance does not fully rescue it.
- **`MetzProject/ServiceSoup` produced zero findings across all five apps**
  despite being validated/default-eligible. Not wrong — these apps mostly do
  not use `.call`-style service objects — but worth remembering that the
  headline analyzer is silent on many real codebases.

## Findings that earned their space

- `MetzProject/RepeatedBranching` was the standout across all five projects:
  redmine's `params[:format]` triple (News/Queries/SearchController),
  `v.custom_field.field_format` across three import classes, and `operator`
  across query classes; huginn's duplicated `faraday_backend` branch
  (OpenaiConcern/WebRequestConcern) and `interpolated['mode']`
  (FTP/S3 agents); maybe's `per_page` and `@authentication_method`;
  rubygems.org's `api_key_owner` and `range`. All verified real
  cross-file duplication with actionable consolidation advice.
- `Metz/ClassesTooLong` top offenders are exactly the files a reviewer would
  name (lobsters `story.rb` [1095/100], `comment.rb` [480/100]; redmine
  `account_controller.rb` [341/100]).
- `Metz/DemeterTrainWreck` counts of 8-10 pointed at genuinely gnarly chains.
- The project-analyzer triage header (status/confidence/severity plus counts)
  reads well and makes the advisory framing clear.
