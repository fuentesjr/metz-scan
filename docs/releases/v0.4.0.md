# v0.4.0 Release Notes

Release notes for the `metz-scan` and `rubocop-metz` `v0.4.0` release.

## Highlights

- Adds candidate opt-in analyzers for implicit context pressure, repeated query
  criteria, and subclass override pressure.
- Improves project-analyzer calibration reporting with persisted JSON/Markdown
  artifacts, notable findings, readiness/backlog output, and target manifests.
- Extends cross-package metadata and triage for package dependency and
  namespace leak pressure without promoting those analyzers to default output.
- Hardens release readiness with published-gem smoke checks, release issue
  dry-run coverage, package metadata tests, and CI-parity validation.

## Release Readiness

- Both gems now report `0.4.0`.
- Candidate analyzers remain opt-in behind `--project-analyzers`.
- Default scan output remains limited to validated, default-output-eligible,
  medium-confidence design-pressure findings.
- Release verification is tracked in issue #30, with `rubocop-metz` published
  before `metz-scan`.
